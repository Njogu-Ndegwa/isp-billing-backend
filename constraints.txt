# Exact versions of every package in the production image, applied with
# `pip install -r requirements.txt -c constraints.txt` (Dockerfile, tests.yml).
#
# Why: the deploy builds with --no-cache, and requirements.txt names most
# packages without a version, so every deploy re-resolved the whole stack
# against whatever PyPI had that minute. On 2026-10-02 that pulled
# SQLAlchemy 2.1.2, which no longer installs greenlet, and the app died on
# import. These pins are `pip freeze` of the image that was healthy in
# production right after that outage.
#
# To upgrade a package: change its line here, let tests.yml run against it,
# and the deploy's pre-swap smoke test will refuse an image that cannot import.
# A package newly added to requirements.txt is unpinned until it is added here.
